# 使用手册

## 管理面板

访问 `https://你的域名/panel/`，输入 api_key（浏览器记住）。七个视图：

| 视图 | 功能 |
|---|---|
| 账号池 | 统计条 + 账号表（状态/积分/成功失败/在途），单号操作：签到、余额、解冻、禁用、暂停选号、移除；批量：全部签到 / 旅行巡检 / 活跃上报 / 全部保活 / 立即刷余额 |
| 用量 | 请求数 / token / 平均延迟 / 吐字速率 + 时序与按账号·模型·域的明细 |
| 积分构成 | 逐账号积分包明细与到期分布 |
| 任务中心 | 全账号成长任务扫描 → 排队执行 → 自动领奖 |
| 模型与档位 | 实时拉取上游模型：倍率 / 思考档 / 上下文 / 最大输出 |
| 配置 | 在线改配置（深合并保存，未知键保留） |
| 运行日志 | 请求记录（结果/模型/账号/来源IP·UA/耗时/Token）+ 分频道运行日志 |

## API 端点

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `POST /v1/chat/completions` | Bearer api_key | OpenAI 兼容；流式 SSE / 非流式聚合 |
| `GET /v1/models` | Bearer api_key | 动态模型列表（缓存 10 分钟） |
| `GET /status` | Bearer api_key | 账号池状态汇总 |
| `GET /healthz` | 无 | 健康检查（无健康账号返回 503），带 `X-Service: workbuddy2api` |
| `GET /cron/<kind>?token=` | cron 令牌 | 定时任务入口 |

## 配置说明（data/config.json，面板可在线改）

关键项（与原版字段一致）：

- `api_key`：网关与面板鉴权密钥；**为空表示不鉴权（仅限内网）**
- `cooldown.soft_rate` / `soft_rate_max`：429 软冷却基数（默认 600s）与指数退避封顶（默认 2h）
- `pool.*`：熔断阈值（3）、熔断冷却（30m，封顶 6h）、降权阈值（5）、积分保底 `credit_floor`（100）、快过期加权等
- `schedule.*`：五类任务时点与开关、余额刷新间隔
- `prompt.mode`：`custom`（默认，替换客户端 system）/ `append` / `passthrough`
- `features.sanitize_blacklist_fingerprints`：出站指纹脱敏（默认开）
- `session_sticky.*`：会话粘性开关与 TTL
- `upstream.*`：超时、出站 UA、测试基址（`test_base_cn` 等，仅测试用）

## 行为语义（与原版一致的部分）

- 出站强制 `stream:true`，SSE 帧按 OpenAI 白名单重建；非流式本地聚合
- 错误分类：402→硬冷却至次日 04:00；429/限流文案→软冷却指数退避（「将在 … 重置」时精确冷却到重置时刻）；404→60 秒短冷却；5xx→喂熔断计数；12153 连续 3 次才禁用；11101/内容拦截/11115 不罚号
- 选号：过滤禁用/冷却/熔断/在途占满 → 模型成本分层 → 积分 + 闲置 + 快过期加权随机 → Top-5 → 防惊群（100ms 内不重复选中）；全冷却时选最早到期者顶班
- 会话粘性：`conversation_id` 优先，缺失时由 system+首条 user 派生 `d-` 键；失败解绑、成功绑定、TTL 滚动续期

## 与 Go 原版的差异（PHP 版限制）

- 无 Upstash Redis 镜像（状态存数据库/文件，本身已持久化）
- 无请求体归档 JSONL 文件体系（请求元数据存数据库/文件存储表，保留量自动裁剪）
- 成长任务的复杂桌面端行为事件链以尽力而为的 report 上报实现；个别依赖官方客户端交互链的任务会如实标注「需客户端交互」，不做伪造
- 模型输出上限探测（probe_max_tokens）为 Go 版外部脚本能力，未内置
- 长流式对话受主机 `max_execution_time` 限制（安装页会检测并提示实际值）
